# 数据契约模板

在写第一行请求代码前填好。示例值仅用于说明格式。

| 项目 | 约定示例 |
|---|---|
| 来源与授权 | `https://example.org/`；公开页面；已核对站点规则和用途 |
| 目标范围 | `articles` 列表的前 10 页，不抓个人资料 |
| 唯一键 | 来源域名 + 文章 ID |
| 必填字段 | `id: str`、`title: str`、`url: absolute URL` |
| 可选字段 | `author: str | null`；缺失时记为 `null`，不猜测 |
| 时间字段 | `published_at` 为原文事实；`fetched_at` 为采集时间，均注明时区 |
| 分页停止 | 接口返回 `next=null`；重复游标报错；最多 10 页 |
| 异常策略 | 401/403 停止；429 按等待指示降速；字段缺失计数并留脱敏样本 |
| 去重与写入 | SQLite 唯一约束；成功写入后推进检查点 |
| 保留与删除 | 原始响应保存 7 天供排错；结构化记录按用途设期限 |

验收时至少报告：请求总数、成功与失败数、失败分类、去重前后记录数、缺失字段数、停止原因、抽样记录与原页面的对应情况。
