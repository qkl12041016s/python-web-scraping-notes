# 运行与脱敏检查

## 发请求前

- 确认目标域名、路径、服务条款、robots 规则、API 契约和账户权限。
- 只采必要字段；写明保留期限和删除策略。
- 设置全局并发、单站点速率、连接/读取超时、有限重试和停止条件。
- 遇到验证码、设备指纹、证书固定、付费墙或访问控制，先确认授权；不默认绕过。

## 日志与分享

- 日志只记录请求方法、脱敏 URL、状态、耗时、错误类别和计数。
- 删除 Cookie、Authorization、API 令牌、代理口令、设备标识、个人信息和敏感响应体。
- HAR 分享前检查请求头、查询串、请求正文、响应正文；导出后重新打开文件复查。
- 截图遮挡不能代替清理原始文件。

## 收尾验收

- 核对请求数、成功/失败数、去重前后数量、缺失字段和停止原因。
- 随机抽样核对来源页与输出，确认标题、链接、时间和来源一致。
- 原始响应和备份到期删除；凭据失效或授权范围变化时停止任务。
